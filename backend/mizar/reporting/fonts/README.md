`DejaVuSans.ttf` is DejaVu Sans 2.37, unmodified, from the official release
archive `dejavu-fonts-ttf-2.37.tar.bz2`
(https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37).

The PDF report uses it only for characters the built-in Helvetica cannot draw
(DESIGN.md D40). ReportLab embeds the subset of glyphs a report uses.
